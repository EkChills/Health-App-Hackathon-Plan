# BST

A photo of a lab report or prescription goes in. Structured, verified health data comes out, explained in plain language for the patient and handed to the doctor as a one-page clinical brief.

## What's in this repo

| Path | What it is |
| --- | --- |
| `PLAN.md` | The full plan. The source of truth. |
| `figjam-stickies.txt` | The plan as sticky-note lines for the team's FigJam board. |
| `plan-page.html` | The plan as a standalone web page. Open it from disk. |
| `API.md` | The API contract between frontend and backend. |
| `PERSONAS.md` | The three seeded demo personas. |
| `frontend/` | The Next.js app. See `frontend/README.md`. |
| `backend/` | The backend. Stack not chosen yet. See `backend/README.md`. |
